# KOSMOROWALI - First Boarding House Platform in Morowali

Live in Morowali, Central Sulawesi - the biggest nickel producer in the world? Finding a Kos is hard. I built the solution.

**Live Demo:** https://Muh-Dudy-Firmansyah.github.io/kosmorowali/ (coming soon)

### 🚀 Problem Solved
- No centralized platform for Kos in industrial area
- Workers need cost-sharing (Patungan) system
- Owners have no way to self-list

### ✨ Features
- **Patungan System:** Cost-sharing for workers
- **Owner Self-Listing:** List your Kos directly
- **Production Ready:** Supabase Auth, RLS Policies, Storage Buckets with 3 Policies (Public Read, Auth Upload, Owner Delete)

### 🛠️ Tech Stack
- Frontend: HTML5, CSS3, Vanilla JavaScript
- Backend: Supabase (PostgreSQL, Auth, Storage, RLS)
- Deployment: GitHub Pages + Supabase Cloud
